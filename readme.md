# Schreinerei Renggli – WordPress Theme

🎨 A custom WordPress theme developed for **Schreinerei Renggli AG** – a traditional carpentry company in Basel, Switzerland, operating since 1943.

---

## 📂 Theme Features

- Custom-built WordPress theme using **ACF (Advanced Custom Fields)**
- Fully responsive layout
- Clean design inspired by existing branding
- Custom homepage with:
  - Hero section
  - About section
  - Service offerings
  - Contact & opening hours
- Lightweight and fast
- SEO-friendly markup
